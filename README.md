## Quick Start

Prerequisite: Node.js 22 LTS or newer (download from [https://nodejs.org](https://nodejs.org)).

### Quick Start: macOS
```bash
git clone <repo-url> facilify
cd facilify
npm install
npm run demo
```
`npm run demo` prints a demo sign-in (email and password) in the terminal and turns on password sign-in for that demo only. Open [http://localhost:3000](http://localhost:3000) and use it.
